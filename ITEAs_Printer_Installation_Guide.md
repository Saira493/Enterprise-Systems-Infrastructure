
ITEAs – Printer Installation Guide
1. Install Printer Using IP Address
a)	Go to Settings → Bluetooth & devices → Printers & scanners
b)	Click Add device
c)	Select Add manually
d)	Add IP address option
e)	Choose: Add a printer using TCP/IP address or hostname
f)	Enter Printer IP address (example: 192.168.2.50)
g)	Click Next
h)	Select correct printer driver (exact model or closest series)
i)	If unsure, use Universal Print Driver
j)	Complete installation
k)	Print a test page to confirm it works
2. If Printer Model is Unknown (Find Using IP)
a)	Open web browser (Chrome or Edge)
b)	Type the printer IP address in the address bar (example: http://192.168.2.50)
c)	Press Enter
d)	Printer web page will open (Konica, HP, Canon, etc.)
e)	Check Printer Model and Name on the page
f)	Note the exact model number
g)	Use this model to install correct driver
3. Alternative Methods (If Browser Does Not Work)
•	Use Command Prompt: ping <IP address> to check hostname
•	Use Advanced IP Scanner to identify device name
•	Check printer physically for model and IP details
