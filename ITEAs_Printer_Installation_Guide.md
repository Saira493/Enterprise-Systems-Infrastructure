
ITEAs – Printer Installation Guide
1. Install Printer Using IP Address
•	Go to Settings → Bluetooth & devices → Printers & scanners
•	Click Add device
•	Select Add manually
•	Add IP address option
•	Choose: Add a printer using TCP/IP address or hostname
•	Enter Printer IP address (example: 19.18.2.50)
•	Click Next
•	Select correct printer driver (exact model or closest series)
•	If unsure, use Universal Print Driver
•	Complete installation
•	Print a test page to confirm it works
2. If Printer Model is Unknown (Find Using IP)
•	Open web browser (Chrome or Edge)
•	Type the printer IP address in the address bar (example: http://192.168.2.50)
•	Press Enter
•	Printer web page will open (Konica, HP, Canon, etc.)
•	Check Printer Model and Name on the page
•	Note the exact model number
•	Use this model to install correct driver
3. Alternative Methods (If Browser Does Not Work)
•	Use Command Prompt: ping <IP address> to check hostname
•	Use Advanced IP Scanner to identify device name
•	Check printer physically for model and IP details
