# ITEAs – IT Setup & Meeting Checklist

## 1. Meeting Checklist (Zoom & Teams)

### Before Joining Any Meeting:
* [ ] Ensure internet connection is stable
* [ ] Headset / speaker connected properly
* [ ] Microphone connected and working

### Zoom Meeting:
* [ ] Open Zoom
* [ ] Join meeting
* [ ] Select correct speaker (output)
* [ ] Select correct microphone (input)
* [ ] Run Test Speaker & Microphone
* [ ] Confirm audio works both ways

### Microsoft Teams Meeting:
* [ ] Open Teams
* [ ] Join meeting
* [ ] Check Audio Settings
* [ ] Select correct speaker
* [ ] Select correct microphone
* [ ] Do test call if needed
* [ ] Confirm users can hear you and you can hear them

## 3. New Device Setup (Accounts & Security)

### Local & Admin Accounts:
* [ ] Create Local Admin Account (first)
* [ ] Create username and secure password

### Important Rules:
* [ ] **Do NOT** rename local account to Admin
* [ ] Login using the Local Admin Account
* [ ] Delete unnecessary user accounts
* [ ] Keep at least one local account active

### Microsoft Entra (Azure AD):
* [ ] Join device to Entra ID
* [ ] Verify user login works
* [ ] Apply company policies
